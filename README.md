# Ignite 2026 AI Apps sessions

Browse the [session shortlist](https://hunhoon21.github.io/ignite-2026-ai-apps/).

The page presents 50 AI Apps candidates in five review groups of 10: six required sessions (KEY01, INV640, INV641, INV642, INV643, BRK542) and 44 detailed candidates. The optional KEY02 partner keynote is outside the 50.

- `index.html` — shortlist and session details
- `assets/ignite-2026.png` — Microsoft Ignite event artwork
- `ignite-2026-ai-apps-50.csv` — the 50 candidates
- `ignite-2026-technical-sessions.csv` — technical-session inventory (804 sessions)
- `ignite-2026-all-sessions.csv` — full inventory (1,343 sessions)

Based on public event/session metadata. The catalog snapshot is dated 2026-11-09; flagship titles were checked 2026-11-20. This is not the official Microsoft event website, and it does not claim that all listed sessions were watched.
